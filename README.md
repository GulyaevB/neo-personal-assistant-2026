# neo-personal-assistant-2026
A team-based Python CLI application for managing contacts, birthdays, notes, and tags. Final project for Neoversity's Python Programming: Foundations and Best Practices course.

## Installation and launch

Requires Python 3.12 or newer. From the repository root, install the package:

```bash
python -m pip install .
```

The installation exposes both entry points. From **any working directory**, run:

```bash
assistant
# or
python -m assistant
```

Type `exit` or `close` to leave the CLI. For development, use `python -m pip install -e .`, then `python -m pytest` to run the tests.
